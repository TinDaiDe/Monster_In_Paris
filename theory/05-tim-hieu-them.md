# 5. Tìm hiểu thêm (không bắt buộc)

Những thứ dưới đây **không cần biết** để làm project. Bạn nào thấy hứng thú thì tìm theo từ khóa. Nguồn đáng tin để đọc: **MDN Web Docs** (về HTML/CSS/JS) và **tài liệu chính thức của FastAPI**.

| Chủ đề | Một dòng giải thích | Từ khóa để tìm |
|---|---|---|
| Tên miền và DNS | Cách tên miền được đổi thành địa chỉ của máy | `DNS là gì` |
| Địa chỉ IP và cổng (port) | Địa chỉ của máy, và "cửa" mà server lắng nghe | `IP address`, `port` |
| TCP | Cách dữ liệu được chia nhỏ và gửi đi đáng tin cậy | `TCP là gì` |
| HTTPS | Phiên bản HTTP có mã hóa, ổ khóa trên thanh địa chỉ | `HTTPS TLS` |
| Header và cookie | Thông tin phụ đi kèm request/response, cookie dùng để "nhớ" người dùng | `HTTP header`, `cookie` |
| Đăng nhập, phiên làm việc | Server biết bạn là ai qua các request | `session`, `authentication` |
| REST API | Cách thiết kế các đường dẫn cho gọn và dễ hiểu | `REST API` |
| WebSocket | Kết nối hai chiều liên tục, dùng cho game và chat real-time | `WebSocket` |
| Cơ sở dữ liệu | Nơi lưu dữ liệu lâu dài, thay vì chỉ lưu trong biến | `SQL`, `SQLite` |
| Deploy | Đưa trang web lên một máy chạy 24/7 để người khác truy cập | `deploy FastAPI` |
| Git và GitHub | Lưu lịch sử code và làm việc nhóm | `Git cơ bản` |
| Bảo mật web cơ bản | Đừng tin dữ liệu người dùng gửi lên | `XSS`, `SQL injection` |
| `async` / `await` | Cho phép server xử lý nhiều request cùng lúc | `Python async await` |

Tất nhiên là mọi hàm và các thứ khác liên quan tới html - css và js bạn tự tìm hiểu thêm nhá
Bạn nào đọc thêm được cái gì hay thì thêm vào bảng này (nhờ bạn chủ trì xem lại cho đúng trước khi gộp).
