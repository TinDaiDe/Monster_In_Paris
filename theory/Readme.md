# Theory: đọc nhanh để hiểu mình đang làm gì

Cả folder này đọc hết khoảng **20 phút**. Không cần học thuộc, chỉ cần hiểu bức tranh lớn để biết các hàm Python mình viết **nằm ở đâu** trong một trang web.

## Bức tranh lớn

```
Người chơi bấm nút trên trang web
        │   (JavaScript gửi một REQUEST)
        ▼
Server nhận request  →  chạy HÀM PYTHON của bạn
        │   (server trả về một RESPONSE)
        ▼
Trang web hiện kết quả cho người chơi
```

Bạn chỉ cần tự viết phần ở giữa (hàm Python). Phần còn lại là "đường ống" để hàm của bạn đến được với người chơi.
